# 수원 ASOS 119 시간자료 — 출처와 QC

- 원본: 기상청 API허브 `kma_sfctm3.php`(typ01 텍스트), 2020–2025년 11·12·1·2월, 2026-10-31 수집.
  `model/data/source/119/OBS_ASOS_TIM_119_api.csv` (sha256 `9df2e18f93d969753ccb62c897a2ce1f4236b71bb83919c006f581536cc76508`)
- 이 폴더의 파일은 원본에 QC만 적용한 것이다. 학습·엔진은 이 폴더만 읽는다.
  `OBS_ASOS_TIM_119_api.csv` (sha256 `598626a2e0190c78561ded952f87721e70702253800d3998467a5cc659e20162`)
- 만든 명령:
  `python3 tools/fetch_asos.py --qc-file model/data/source/119/OBS_ASOS_TIM_119_api.csv --out model/data/raw/119/OBS_ASOS_TIM_119_api.csv`
- QC 규칙(`tools/fetch_asos.py` `qc_values`, 기온·지면온도만): typ01은 결측을 -9.0으로 적는다.
  - 앞뒤 값이 -9°C 근처(±2)가 아닌 -9.0, 또는 6시간보다 길게 이어진 -9.0은 결측으로 바꾼다.
    2023-12에 지면온도가 -9.0으로 117시간 멈춘 구간이 여기에 걸린다.
  - 앞뒤 두 값이 서로 3°C 안인데 가운데 한 시간만 8°C 넘게 튄 값도 결측으로 바꾼다(2023-01-18 06:00 지면 -18.0).
  - 추운 밤 앞뒤가 -8.9·-9.1 같은 실제 -9.0°C는 남긴다(2021-12-26 05:00, 2025-01-09 22:00~01-10 00:00).
  - 결과: 17,325행 중 126개 값을 결측으로 바꿨다.
- 이 폴더에 다른 CSV를 함께 두지 않는다. `kma.load_station`은 폴더의 CSV를 모두 합치며 같은 시각은 값이 더 많은 행을 남긴다.
- 강수(RN)는 이 API에서 주로 3시간마다(00·03·…·21시) 보고된다. 빈칸은 0으로 읽히므로 `precip_6h`는 6시간 동안의 보고 두 번의 합이다.

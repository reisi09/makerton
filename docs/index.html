판단 기록 새 기록이 위

    예측은 진짜 모델 값수원 관측소(학교에서 0.4km)의 2020–2024 겨울로 학습한 XGBoost 모델이, 그 시각까지의 관측만 보고 낸 지면온도 예보와 동결확률이다. 이 밤들은 학습에 쓰지 않은 2025년이다.
    현장 보정 슬라이더갈래 옆 DHT11이 처음보다 몇 도 차가워졌는지(얼음팩을 대면 −)를 흉내 낸다. −6~+3°C의 동결확률을 실제 모델로 미리 계산해 두었다.
    출동 규칙은 서버와 같다눈 감지면 바로. 아니면 어느 갈래든 확률 0.5 이상이고 최근 3시간 안에 제설하지 않았을 때. 차는 광장을 북쪽으로 밀고 같은 길을 후진한다(실물 약 44초, 화면 6초).
    무엇이 시뮬레이션인가차의 움직임과 눈 조각은 화면 그림이다. 실물 모형에서는 맥북 서버가 같은 판단을 하고 Wi-Fi로 Pico 제설차를 움직인다.
    예측 동결확률은 결빙 확정이 아니다 · 자료 docs/demo/replay.json (tools/export_demo.py로 생성)

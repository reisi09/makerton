## 0. 결론
**작업대마다 피코 '안전 비콘'을 두고, 노트북의 LLM과 연결한다.** 외국인 노동자가 지금 무슨 경보인지, 무엇을 해야 하는지를 **자기 언어로 묻고 다시 묻는다.** 답은 **공식 문서 구절을 인용해서만** 하고, 이해했는지도 확인한다.
- 긴급 경보와 긴급 지시는 피코의 규칙과 사전 승인 문안만 쓴다. LLM은 이를 바꾸지 못한다.
- 교육·설명을 돕는 장치다. 기존 경보기나 대피 체계를 대체하지 않는다.

## 2. 피코가 필요한 이유 (과장 금지 포함)
1. **네트워크와 무관하게 즉시 경보한다.** 센서 입력에서 LED·부저까지 피코가 직접 처리한다. 노트북이나 API가 죽어도 경보는 울린다.
2. **작업대 단위 맥락을 제공한다.** 어느 작업대에서 어떤 신호가 났는지가 LLM 질문의 맥락이 된다. "지금 이 경보"에 대해 물을 수 있는 이유다.
3. **현장에서 쓰기 쉽다.** 장갑을 낀 채 누르는 큰 버튼과 언어가 필요 없는 빛·소리 패턴을 쓴다. 휴대폰 앱만으로는 이런 상호작용을 만들 수 없다.
- **과장 금지**: '피코만 가능'하다고 하지 않는다. 기본 센서(상대값)로 안전 여부를 판정하지 않는다. 산업용 경보기를 대체하지 않는다.

## 3. LLM이 확실히 좋은 이유 (과장 금지 포함)
1. **비정형 질문과 후속 질문**: 작업자가 자기 언어로 "이 소리 뭐예요? 물 뿌려도 돼요?"라고 묻고, 못 알아들으면 다시 묻는다. 고정 번역문은 미리 쓴 문장만 보여 줄 수 있다.
2. **근거에 연결된 설명**: 공식 MSDS, 공단 다국어 자료, 현장 대피도 가운데 관련 구절을 찾아 작업자 언어로 설명하고, 원문 구절을 함께 보여 준다.
3. **이해 확인**: "불이 나면 어느 비상구로 가나요?"에 대한 자유 답변을 평가하고, 오해를 그 언어로 바로잡는다. 관리자에게는 한국어로 요약해 준다.
- **과장 금지**: 정확도나 학습 효과가 더 낫다는 것은 미검증이다. 시연과 비교 측정으로 보인다(§6).

## 4. 파이프라인
```
[피코 비콘 · 작업대]  센서: 온도, 가스(MQ, 상대값), 불꽃 / 출력: 경광 LED·부저(그림 신호) / 버튼: 확인·질문
   ├─ 로컬 규칙: 이상 신호 → 즉시 경보 + 사전 승인 다국어 고정 문안 번호        (인터넷 불필요)
   └─ USB → 노트북: 이벤트 맥락(작업대 3, 온도 급상승, 시각)
작업자 휴대폰·태블릿 웹 화면(자기 언어) → 질문
   → LLM(chat, `x-cmd-zdr: 1`): 근거 문서에서 관련 구절 선택 → 작업자 언어로 설명 + 원문 인용
   → 코드: 인용 구절이 실제 문서에 있는지 대조 → 없으면 보류("관리자 확인 필요")
   → 이해 확인 질문 → 자유 답변 평가 → 교정 / 관리자용 한국어 요약(승인 후 기록)
```
- **개인정보**: 이름·국적 대신 언어 코드만 쓴다. chat은 ZDR 헤더를 붙인다(`deepseek-v4.1-flash`는 HTTP 200 확인). jev에는 문장을 보내지 않는다.

## 5. 12시간 MVP (GPT 수정 반영)
- **비콘 1대**: 온도 센서, MQ 가스 센서, 버튼 2개, LED·부저
  - 실제 유해가스 시험은 하지 않는다. 알코올 솜 같은 안전한 자극으로 상대 변화만 보인다.
- **근거 문서**: 공개 MSDS 1종, 모형 현장 대피도 1장, 공단 다국어 자료 일부. 언어는 2~3개(예: 베트남어, 중국어)
- **LLM**: 근거 인용 Q&A, 후속 질문, 이해 확인
- **12시간에서 뺄 것**: STT, 억지로 넣는 서보, 다중 비콘, 앱 배포, 근태 연동
- **역할**
  - 하드웨어: 비콘과 모형 작업대
  - 펌웨어: 로컬 경보 규칙, 이벤트 전송
  - LLM·서버: 웹 화면, 인용 대조, 이해 확인
- **스타터 재사용**: USB 브리지, 대시보드, `call_api`/`chat_text`(`reasoning_effort`)

## 6. 시연 장면과 LLM 필요성 검증
- **장면 A, 오프라인 분리**: API 연결을 끊고 센서에 자극을 준다. 로컬 경보는 정상으로 울리고, 문서 대화는 '이용 불가'로 따로 표시된다.
- **장면 B, 외국어 질문과 재질문**:
  - 베트남어로 "이 경보 뭐예요? 물 뿌려도 돼요?"라고 묻는다.
  - 근거 구절과 함께 설명이 나온다.
  - "이해 못했어요"라고 하면 설명 방식을 바꾼다.
  - 이해 확인 질문을 하고 답변을 평가한다.
- **검증 방법**: 공단 고정 번역문 그대로 보여 주기와 비교한다. 비교 항목은 후속 질문 응답, 인용 대조 통과율, 근거 밖 질문의 보류율이다. 실측하기 전에는 수치를 쓰지 않는다.
- **확장(시간이 남으면)**: 대피 훈련 모드. 부저 패턴을 울리고 확인 버튼 반응 시간을 기록한 뒤, 언어별 이해 격차를 관리자에게 요약한다.

## 7. 위험과 미검증
- **오역·환각**: 원문 인용을 함께 보여 주고 근거 밖 질문에는 답을 보류한다. 긴급 지시는 고정 문안만 쓴다.
- **안전 과신**: 교육·설명 보조라고 명시한다. 기본 센서로 안전을 판정하지 않는다.
- **언어 품질**: 팀이 해당 언어를 모르므로 공단 공식 번역과 대조하거나 원어민 검토가 필요하다[미확보]. 저자원 언어의 답변 품질은 미검증이다.
- 인용 대조 로직, MQ 센서 반응, 공단 자료를 실제로 어디까지 확보할 수 있는지도 미검증이다.
- **철회한 대안**: 치매 야간 배회 대화 동반자. 실종 통계는 탄탄하다(연합뉴스 2024-10-14, 매일경제 2025-10-24). 하지만 대화의 효능은 미검증이고, 대화 지연과 STT 위험이 있다.

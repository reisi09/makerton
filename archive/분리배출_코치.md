# AI 분리배출 코치 스테이션 (11라운드 최종, 2026-10-31 KST)

> 사용자 피드백: "주제 너무 별론데 지속가능발전 유의중? GPT랑 또 토의."
> Claude와 GPT-6-Astra(max)가 각자 SDG 중심 후보를 냈다. GPT의 1순위는 급식 배식 실험대(SDG 12.3)였다. 비교 끝에 **Claude 안을 양측 1순위로 합의했다.**
> 원문: `debate/claude_round11_sdg.md`, `astra/round11_sdg.md`, `astra/round11_verdict.md`

## 0. 한 줄 요약
**버리는 순간에 개입하는 분리배출 코치.** 사람이 품목을 말하거나 입력하면, LLM이 공식 분리배출 지침을 근거로 애매한 점을 되묻는다. 피코는 투입구에서 무게·젖음·전도 반응을 재고, 맞는 칸의 덮개를 열고 LED로 안내한다.
- **SDG 12.5**: 예방·감축·재활용·재사용으로 폐기물 발생을 크게 줄인다. 다른 목표를 늘어놓아 강점을 부풀리지 않는다(GPT 지적).

## 1. 왜 지금 수원에서 이 문제인가 (뉴스 확인)
| 사실 | 출처 |
|---|---|
| 수원 소각장(2000년 가동, 300t×2기, 하루 최대 600t)은 내구연한을 넘겼다. 이전 후보지 공모는 2023년 신청 0건이었고, 2026-10-07~12-06 재공모 중이다 | [SBS 2026-10-08](https://news.sbs.co.kr/news/endPage.do?news_id=N1008788731) |
| **2027년 1~2월 대보수에 착수하면 2년간 자체 소각이 불가능하다.** 2026년부터 수도권 직매립 금지 원칙이 시행되며, 경기도 예외 허용량은 연 45,415t이고 수원 생활폐기물은 연 약 135,000t(3배)이다. 민간 위탁 소각은 t당 11만~21만 원으로 매립지보다 최대 40% 비싸다 | 같은 기사 |
| 2024년 폐플라스틱 '재활용' 65% 중 물질 재활용은 26%였다. 종량제 봉투에 섞인 플라스틱의 물질 재활용은 6.2%였다. 업계는 "아파트 분리배출분도 선별하면 약 30%가 잔재물"이라고 말한다(사진 촬영지: 수원시자원순환센터) | [중앙일보 2026-09-22](https://www.joongang.co.kr/article/25463875) |
| 수원 민원 키워드(2019~2025)에서 소각장 폐쇄는 2021~2024년, 영통 소각장은 2023년, 영통 노후는 2022~2024년, 쓰레기 투기는 2025년에 나온다 | `data/evidence_summary.md` E2 |
| 분리배출 기준: 「재활용가능자원의 분리수거 등에 관한 지침」(2026-01-01 시행) | [국가법령정보센터](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000272746) |
| 기존 해법인 '내 손안의 분리배출' 앱(품목 검색)이 있다 | [정책브리핑 2025-05-07](https://www.korea.kr/news/policyNewsView.do?newsId=148942796) |

- **해석의 한계**: 소각장 위기는 '왜 지금 수원인가'의 배경이다. 이 장치가 소각량을 줄인다는 증거는 아니다. 실측 전에는 감축 효과를 주장하지 않는다(GPT 지적).

## 2. 앱과 무엇이 다른가 (핵심 차별점)
- 앱은 사람이 **찾아볼 때만** 정보를 준다. 이 장치는 **버리는 순간**에 개입한다.
- 애매한 설명에는 지침 근거로 **되묻고**, **실제 배출구를 연다.**
- 예: "피자 상자" → "기름이나 음식물이 묻어 있나요?" → 묻어 있으면 일반, 깨끗하면 종이. 근거 조항을 인용한다.

## 3. 피코가 필요한 이유
| 역할 | 부품 | 비고 |
|---|---|---|
| 투입 감지 | 적외선 빔(장애물 센서) | 넣었는지, 어느 칸에 넣었는지 |
| 무게 | 로드셀 + HX711 | 추가 약 1만 원[추정]. 이상하게 무거우면(내용물 남음 등) 되묻는 단서 |
| 젖음·전도 반응 | 수분 센서 판(2전극) | **재질 판별이 아니라 상태 단서만.** 예: 젖어 있음 → "헹궜나요?" |
| 덮개 개방 | SG90 서보 ×3(플라스틱·캔·일반) | 확인된 칸만 연다 |
| 안내 | LED·부저 | 오프라인이면 '사람 안내 모드' 표시 |
- 모든 동작은 네트워크와 무관하게 피코가 처리한다. LLM 응답이 없거나 불확실하면 **덮개를 열지 않는다.**

## 4. LLM이 필요한 이유
- **끝없이 다양한 품목 설명**: 컵라면 용기, 기름 묻은 피자 상자, 보조배터리, 영수증, 코팅 종이컵 등. 룩업표는 미리 넣은 품목만 처리한다.
- **확인 질문**: 지침상 조건이 갈리는 지점을 묻는다. 예: 음식물 잔여, 코팅, 다른 재질 결합, 배터리 내장.
- **센서와 말의 충돌 해결**: "깨끗한 플라스틱 컵"이라는데 젖음 반응이 있으면 다시 묻는다. 센서는 재질을 정하지 않는다. 재질은 사람에게 확인한다.
- **근거 인용과 코드 대조**: 답에 지침 조항을 인용하고, 코드가 그 구절이 실제 원문에 있는지 대조한다. 불일치하면 보류한다.
- **관리자 요약**: 주간 오투입·보류 사례의 원인을 요약한다(사람 승인 후 기록).

## 5. 파이프라인
```
사람: 품목 입력(텍스트·버튼)  →  피코: 투입 대기, 무게·젖음 측정
 → 노트북: LLM(chat, x-cmd-zdr: 1)이 지침 근거로 판단 + 확인 질문
 → 코드: 인용 대조, 센서 단서와 충돌 확인, 확신 낮으면 보류
 → 피코: 확인된 칸만 덮개 개방 + LED / 보류면 '관리자 확인' 표시
 → 투입 감지로 실제 투입 칸 기록 → 오투입·보류 로그 → 주간 요약(승인 후)
```

## 6. 12시간 MVP
- 3칸 모형 투입함(플라스틱·캔·일반), 로드셀 1, 수분 센서 판 1, 적외선 빔 3, 서보 3, LED·부저
- 근거 문서: 지침 원문 중 해당 품목 조항, 수원시 배출 요령 발췌
- 웹 질문 화면(텍스트), 인용 대조, 보류 처리, 로그
- **12시간에서 뺄 것**: 카메라·재질 자동 판별, 음성(STT), 실제 수거 연동, 다국어 확장
- **역할**
  - 하드웨어: 투입함과 덮개
  - 펌웨어: 센서와 서보, 로컬 규칙
  - LLM·서버: 질문 흐름, 인용 대조, 로그와 요약
- **스타터 재사용**: USB 브리지, 대시보드, `call_api`/`chat_text`, 도구 호출(실호출로 확인)

## 7. 90초 시연
1. **애매한 품목**: "피자 상자" → 확인 질문 → "기름 묻었어요" → 근거 조항을 표시하고 일반 칸을 연다.
2. **센서와 말의 충돌**: "깨끗한 플라스틱 컵"이라고 한 뒤 젖은 컵을 올린다 → 젖음 단서로 되묻는다 → 헹군 뒤 플라스틱 칸을 연다.
3. **불확실하면 보류**: 지침에 없는 품목을 넣으면 덮개를 열지 않고 '관리자 확인'을 띄운다. 인터넷을 끊으면 사람 안내 모드로 바뀐다.

## 8. 앱 대비 실익 검증 (GPT 필수 수정)
- 같은 품목 조건(팀이 미리 정하지 않은 품목 설명 포함)을 두 방식에 똑같이 준다. 한쪽은 '앱 검색 결과만 보고 투입', 다른 쪽은 '코치 사용'이다.
- 오투입 수, 보류 수, 걸린 시간을 비교한다. 차이가 없으면 LLM 실익 주장을 철회한다.
- 실측 전에는 수치를 쓰지 않는다.

## 9. 위험
- **센서 과신**: 젖음·전도 반응은 재질 식별이 아니다. 재질은 사람에게 확인하고, 불확실하면 열지 않는다.
- **감축 효과 미검증**: 소각량 감축이나 소각장 문제 해결을 주장하지 않는다.
- **지침 해석 오류**: 인용 대조와 보류로 줄인다. 지역별 배출 요령 차이는 수원시 자료로 보완한다.
- **미검증**: 판 센서의 실제 반응, 로드셀 안정화, 품목 질문의 실호출 품질

## 10. 차순위
- 2위는 급식 배식 실험대(SDG 12.3)다. 경기도교육청 「2026년 학교급식 기본방향」에 따르면 2024년 도내 급식학교 음식물쓰레기는 61,226톤, 처리비는 108억 원이다(원문 p.8에서 확인).
- 3위는 두 안의 통합안이다. 12시간 안에 검증할 범위가 너무 넓어 불리하다.

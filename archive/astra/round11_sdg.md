# 11라운드: SDG 중심 독립 제안

## 결론과 공통 설계
- **1순위: 「남긴 이유까지 묻는 급식 배식 실험대」.** 폐기물 처리 뒤가 아니라 발생 전의 조리·배식을 바꾼다. 나머지 후보는 저전압 제품 수리와 과잉관수 방지다.
- 비초보 2~3인·12시간에 **셋 중 하나만** 제작한다. Pico WH 1대와 기본 센서·버튼·LED, 기존 노트북을 사용한다. 아래 제작 가능성·추가 부품가는 [추정]이며 구매 견적·재고는 미확인이다.
- Pico는 센싱·상태 유지·로컬 반응, 노트북은 USB 연결·텍스트 UI·문서 검색을 맡는다. Pico만 가능한 기능이라는 뜻이 아니라, 인터넷·LLM과 독립된 현장 MCU가 필요한 설계다.
- LLM은 `deepseek-v4.1-flash`로 자유서술·후속 질문을 처리한다. 실호출 3.4~4.1초는 사용자 제공 결과이며 이번에는 API를 호출하지 않았다. STT·jev는 제외하고 이름·연락처를 보내지 않는다.
- 센서 수치·합계·임계값 계산은 코드, 긴급 동작은 Pico 규칙, 실행 승인은 사람에게 둔다. 코드가 문서 ID와 인용문을 원문과 대조하고 불일치는 보류한다. 인용 일치가 해석의 정답까지 보증하지는 않는다. 위반·자격 판정은 하지 않는다.
- SDG 세부목표는 [UN 2030 Agenda](https://sdgs.un.org/2030agenda)의 12.3·12.5·6.4로 확인했다. 환경 효과와 LLM 우위는 아직 미검증이며, 아래 시연은 검증 계획이지 실행 결과가 아니다.

## 후보 1 — 남긴 이유까지 묻는 급식 배식 실험대
- **SDG 12.3:** 2030년까지 소매·소비 단계의 1인당 식품폐기물 절반 감축에 기여. 수원 학교 급식실을 적용 대상으로 제안한다.
- **뉴스:** 아이뉴스24, 2025-02-17. 경기 북부청사 잔반관리 시범운영에 하루 약 150명이 참여했고, 응답자의 80%가 도움이 된다고 답했다. 실제 감축률이 아닌 설문 결과다. [기사](https://www.inews24.com/view/1814668)
- **정부 근거:** 경기도교육청 「2026년 학교급식 기본방향」 p.7: 2024년 도내 급식학교 음식물쓰레기 **61,226톤·처리비 108억원**. p.51은 기호도 조사와 적정량 조리·배식을 통한 발생 억제를 제시한다. 전체 음식물쓰레기를 식판 잔반으로 바꿔 읽지 않는다. [원문](https://www.goe.go.kr/resource/goe/na/bbs_2675/2026/02/29bad70f-478d-472d-aeca-ed9a951a77a4.pdf)
- **연구 근거:** 최지연·이경은(2019), 경기 영양(교)사 594명 응답 분석에서 학생 참여와 음식 품질 개선을 제안했다. 조사 시점은 2015년으로, 현재 규모가 아니라 설계 방향의 보조 근거다. [논문 초록](https://scienceon.kisti.re.kr/srch/selectPORSrchArticle.do?cn=JAKO201908662572910)
- **해결 방식:** 이미 있는 계량·포인트 지급을 반복하지 않는다. 메뉴별 무게와 익명 식사 설명을 묶어 영양교사가 다음 급식에서 시험할 변경안 하나를 고른다. 학생에게 다 먹으라고 압박하는 장치가 아니다.
- **Pico 필수 역할:** 로드셀에서 용기 무게를 빼고 안정된 배식·반납 무게를 기록하며, 승인된 소량/보통 배식 기준을 LED로 안내한다. 인터넷이 끊겨도 계량·버튼 전환·안내가 작동해야 한다.
- **LLM 필수 역할:** 같은 잔반량도 “양은 맞았는데 늦게 받아 식었다”, “소스가 섞여 못 먹었다”면 확인할 사실과 개선안이 다르다. 자유서술의 시간·부정·복합 이유와 조리실 제약을 읽어 필요한 질문을 만들고 공식 지침에 연결한다. 무게 임계값·메뉴 룩업만으로는 이 맥락을 얻을 수 없다.
- **12시간 MVP:** 메뉴 1개·저울 1대·익명 용기 ID로 배식 전후를 연결한다. 모형 식재료, 이유 입력, 후속 질문, 근거 구절, 담당자 승인, 다음 배식 LED까지 구현한다. 음식 인식·영양 처방·자동 조리는 제외한다.
- **추가 비용 [추정]:** 5kg 로드셀+HX711 10,000원, 계량판·고정재·용기 5,000원, 합계 약 **15,000원**. 기본 LED·버튼은 키트 사용.
- **90초 시연:** 0~20초 같은 반납 무게를 계량 → 20~50초 서로 다른 이유에 서로 다른 확인 질문 → 50~70초 사람 승인으로 ‘소량 선택’ 또는 ‘소스 분리’를 선택 → 70~90초 인터넷을 끊고 승인된 배식 기준에 따른 계량·LED 동작을 보인다.
- **최대 위험:** 자발적 응답을 전체 학생의 원인으로 일반화하거나 무조건 배식량을 줄이는 것. 원인은 가설로 표시하고 영양교사 검토·추가 배식 선택권을 유지한다. 복합 메뉴·국물·뼈는 이 MVP에서 자동 분류하지 않는다.
- **성과 지표:** 같은 메뉴·비슷한 식수에서 순수잔반 g/식과 배식량, 미배식 잔식을 따로 비교한다. 90초 모형 시연으로 실제 음식물·탄소 감축을 주장하지 않는다.

## 후보 2 — 버리기 전 한 번 더: 저전압 제품 수리 실험대
- **SDG 12.5:** 수리·재사용으로 폐기물 발생을 예방한다. 경기 수리 모임·학교 메이커실에서 배터리 없는 5V USB 제품을 대상으로 삼는다.
- **뉴스:** 아주경제, 2025-09-19. 「경기도 고쳐쓰는 수리 문화 확산 지원 조례안」 본회의 통과; 부품 부족·매뉴얼 미제공·비용 문제가 보도됐다. 조례 통과를 실제 수리 인프라 완성으로 해석하지 않는다. [기사](https://www.ajunews.com/view/20250919165629358)
- **국제 연구:** ITU·UNITAR, 2024-03-20 발표. 2022년 세계 전자폐기물 **6,200만톤**, 공식 수거·재활용 기록 비율 **22.3%**. 경기 발생량이나 본 장치의 감축률은 아니다. [원문](https://unitar.org/about/news-stories/press/global-e-waste-monitor-2024-electronic-waste-rising-five-times-faster-documented-e-waste-recycling)
- **해결 방식:** “안 켜진다”는 말만 듣고 제품을 버리는 대신, 케이블·전원 조건을 분리해 확인하고 실제 측정이 붙은 수리 상담 기록을 만든다. 범용 가전 자동 진단기는 아니다.
- **Pico 필수 역할:** INA219로 부하측 전압·전류를 읽고 승인된 시험 부하를 켜며, 시간·전류 한계를 넘으면 로컬에서 차단한다. 별도 하드웨어 전류제한도 둔다. API 응답을 기다리는 전원 차단은 허용하지 않는다.
- **LLM 필수 역할:** “어댑터에서는 되는데 노트북에서는 가끔 꺼지고, 선을 바꿨는지는 기억 안 난다” 같은 불완전한 이력을 측정과 대조해 다음 확인 질문·비교 시험을 제안한다. 고정 고장코드 룩업이 아니라, 설명의 모순·미확인 조건을 정리하는 역할이다. 전압만으로 고장 원인을 확정하지 않는다.
- **근거 문서:** 측정 한계·배선 설명은 [Adafruit INA219 제조사 가이드](https://learn.adafruit.com/adafruit-ina219-current-sensor-breakout)를 사용한다. 이 자료에 없는 제품 내부 수리 지시는 생성하지 않는다.
- **12시간 MVP:** USB LED등 1개, 교체 케이블, 스위치식 고장 모사 지그, 무부하/부하 비교와 사람이 승인하는 재측정까지. 220V·충전기 분해·리튬배터리·USB PD 협상은 제외한다.
- **추가 비용 [추정]:** INA219 5,000원, 전류제한·차단부 10,000원, USB단자·시험저항·케이블 7,000원, 5V전원·USB등 10,000원, 합계 약 **32,000원**.
- **90초 시연:** 0~20초 고장 모사 지그에서 등이 꺼지는 현상 관측 → 20~50초 자유서술과 계측을 바탕으로 비교 시험 제안 → 50~70초 승인·케이블 조건 변경 후 점등 확인 → 70~90초 인터넷 없이 안전 범위의 저항 부하로 낮춘 시험 임계값을 넘어 차단되는 장면.
- **최대 위험:** 소프트웨어 차단을 인증된 전기 안전장치로 오인하는 것. 전원·부하의 정격과 하드웨어 보호를 먼저 확보하고, 미해결 고장은 전문가에게 넘긴다. 재사용 안전성·수리 자격은 판정하지 않는다.
- **성과 지표:** 원인 확정 없이도 재현 조건과 다음 확인 사항이 명확해지는지, 교체 전후 기능이 실제 달라지는지 확인한다. 모사 고장을 복구한 수를 폐기 회피 실적으로 세지 않는다.

## 후보 3 — 더 주기 전에 확인하는 절수 관수대
- **SDG 6.4:** 물 이용 효율 향상. 경기 소규모 재배지의 관리 인수인계와 관수 판단을 돕되, 수원에 현재 가뭄이 발생했다고 가정하지 않는다.
- **뉴스:** 인천일보, 2025-08-04. 경기농업기술원이 벼·콩의 고온·가뭄 등 생육 스트레스 예측 시스템 개발 착수를 발표했다. 계획 보도이며 완료·성능 입증은 아니다. [기사](https://www.incheonilbo.com/news/articleView.html?idxno=1298417)
- **지역 연구:** 경기농업기술원 「2024년도 시험연구보고서」: 2022~2023년 5개 관수 처리를 비교했고, 2024년 포천 실증에서 지표점적의 수량이 무관개보다 **23% 증가**했다. 이는 절수율이 아니며, 보고서는 토양별 관수 개시·정지점 설정을 강조한다. [원문 pp.876–890](https://nongup.gg.go.kr/wp-content/uploads/sites/2/2025/06/report_24_reso_05.pdf)
- **해결 방식:** 단순 ‘마르면 물 주기’가 아니라, “방금 물을 줬다”는 관리자의 설명과 건조 센서값이 충돌할 때 측정 위치·관수 이력을 확인한 뒤 관수하도록 돕는다.
- **Pico 필수 역할:** 토양수분·수위 감지, 승인된 제한시간 펌프 구동, 과습 기준·빈 물통·센서 이상 시 정지를 로컬에서 수행한다. 물은 별도 5V 전원과 드라이버로 구동하고 GPIO에 펌프를 직접 연결하지 않는다.
- **LLM 필수 역할:** 자유형 인수인계에서 ‘어느 화분에 언제 얼마나 줬는지’의 누락·모순을 찾아 질문하고, 토양 조건별 설정이 필요하다는 연구 근거를 설명한다. 고정 수분표는 말 속의 대상·시간 관계를 해석하지 못한다. 관수량 계산과 자동 정지는 규칙으로 남긴다.
- **12시간 MVP:** 같은 토양의 화분 2개, 보정한 수분센서, 물통 1개·펌프 1개, 계량컵으로 실제 토출량 확인, 텍스트 확인 질문·승인 버튼까지. 작물 진단·생장 예측·농약 추천은 제외한다.
- **추가 비용 [추정]:** 정전용량식 수분센서 2개 6,000원, 펌프·드라이버·보호 다이오드·호스 8,000원, 수위 스위치 3,000원, 별도 5V전원 5,000원, 합계 약 **22,000원**. 키트 보유분은 차감 가능.
- **90초 시연:** 0~20초 센서는 건조인데 “이 화분에는 방금 물을 줬다” 입력 → 20~50초 LLM이 화분·센서 위치 확인 요청 → 50~70초 사람이 같은 깊이로 재측정한 뒤 젖은 화분은 보류, 마른 화분만 승인 관수 → 70~90초 인터넷을 끊고 물통 수위를 내려 로컬 정지 확인.
- **최대 위험:** 저가 센서의 상대값을 체적수분율로 오인하고 연구의 임계값을 그대로 이식하는 것. 같은 토양에서 보정하며, 잎 시듦의 원인이나 장기 생육 안전성은 판단하지 않는다.
- **성과 지표:** 동일 초기 조건에서 시간제 급수와 실제 사용 mL·과습 차단을 비교한다. 식물 건강을 유지한 절수 효과는 장기 재배 없이는 미확인이다.

## 1순위 선정 이유와 제작 판정 기준
- **후보 1을 선택한다.** SDG 12.3과 지역의 실측 문제 규모가 직접 이어지고, 영양교사가 승인할 변경안과 g/식이라는 결과 지표가 있다. 센서는 ‘얼마나’, 언어는 ‘어떤 사정으로’를 맡아 결합 이유가 가장 분명하다.
- 차별점은 챗봇 답변이나 잔반 포인트가 아니라 **계량 → 원인 확인 질문 → 사람 승인 → 다음 배식 변경 → 재계량**이다. 현재 제품에 없는 기능이라고 단정하지 않으며, 효과는 실험으로 입증해야 한다.
- 후보 2는 물리적 시연이 강하지만 보호 회로·제품별 진단 자료가 부담이다. 후보 3은 로컬 제어가 명확하지만 일반 자동관수보다 LLM이 얼마나 나은지와 생육 영향의 입증이 더 어렵다.
- **12시간 배분 [추정]:** 0~4시간 저울 고정·보정/문서 발췌 병행, 4~8시간 Pico 상태 처리/텍스트 Q&A 병행, 8~10시간 승인·LED 통합, 10~12시간 통신 단절·새 질문·90초 시연. 2인이면 문서·시연 담당을 앱 담당이 겸한다.
- **검증 문턱:** 키워드 룩업과 LLM에 같은 미공개 자유서술을 주고, 부정·복합 이유·추가 답변에 따라 필요한 확인 질문이 달라지는지 비교한다. 잘못된 감량 제안·근거 없는 결론도 함께 센다. 단순 분류와 동률이면 LLM 우위를 주장하지 않는다.
- **현재 확인 범위:** 기사·정부 문서·연구 초록/보고서의 해당 내용을 열어 대조했다. 실제 하드웨어, 감축 효과, LLM 정확도는 확인하지 않았고 Command Code API도 호출하지 않았다.

- 통신은 **USB 기본, Wi-Fi 선택**이다(`pico/config.py` TRANSPORT="usb"). USB 모드에서 중계 서버는 `HOST=127.0.0.1`로 연다.
- chat 모델(deepseek-v4.1-flash)은 대시보드에서 사람이 버튼을 누를 때만 부른다. 자동 생성은 없다.
- 스타터 수정 사항
  - action 확률이 `min_p`(0.80, 검증 전 초기값) 미만이면 `review`
  - `seq`를 왕복시키고 다른 요청의 응답은 버림
  - Wi-Fi 재연결이 루프를 막지 않음
  - 초음파 무반사는 센서 오류(파랑)로 처리
  - API 6초, 피코 8초 시간 제한
  - 프로필 5개(`relay/profiles.json`) 작성. 시작할 때 선택지와 단계가 맞는지 검사함

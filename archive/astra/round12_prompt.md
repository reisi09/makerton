# 12라운드: 최근 트렌드로 과제 재확인 (독립 조사)

## 사용자 피드백
"너무 SDG 성격이 강해 보임. 최근 트렌드 조사해서 다시 확인."
- 11라운드 합의안 「AI 분리배출 코치 스테이션」(SDG 12.5)이 교과서적 SDG 프로젝트처럼 보인다는 뜻이다.
- 대회 규칙상 SDG는 하나 이상 골라야 한다. 다만 사용자는 **SDG가 헤드라인이 아니라, 최신 기술 트렌드가 돋보이는 과제**를 원하는 것으로 해석한다(Claude 해석).

## 유지되는 조건
- 2026 수원고교 피지컬 AI 메이커톤(2026-10-31~11-01), 비초보 2~3인, 제작 12시간
- 하드웨어: Pico WH + 기본 센서·서보 + 노트북 중계. 카메라 없음(추가하려면 가격 표시)
- AI: Command Code API. chat `deepseek-v4.1-flash`는 도구 호출 실호출 정상(3.4~4.1초), 루프 10~16초. jev(확률 분류)는 ZDR 미지원. STT 없음
- 이전 교훈
  - 구조화된 센서 값만 있으면 규칙이 이긴다.
  - LLM은 비정형 언어, 문서 근거, 후속 질문, 도구 계획에서 제값을 한다.
  - 안전 동작은 규칙이 맡고, 사람이 승인한다.
- 사용자 요구 누적
  - 뉴스 등으로 정보를 넓힌다.
  - 피코를 쓰는 이유가 확실해야 한다.
  - LLM이 확실히 이득이어야 한다.
  - 수준 있는 과제여야 한다.
  - 주제가 매력 있어야 한다.
- 기각된 주제: 접근성 경로 안내, 승차 인계, 수거 넘침, 배수 재실험, 공사 소음, 등굣길 위험 조사관, 민원 현장 조사 에이전트(보류), 치매 대화 동반자, 외국인 노동자 안전 코치, 분리배출 코치(SDG 과다로 재검토 중)

## 할 일 (`astra/round12_trend.md`, 한국어, 70줄 이내)
1. **웹 조사**: 2025~2026년 최근 트렌드를 출처 URL·날짜와 함께 정리한다.
   - (a) 피지컬 AI·임베디드 AI. 한국 정부·산업 동향 포함
   - (b) LLM 에이전트(도구 호출, MCP 등)와 하드웨어 결합
   - (c) 최근 대형 해커톤·학생 대회 수상작에 나타난 경향
   - (d) 메이커·교육용 보드(라즈베리파이·ESP32) AI 프로젝트 유행
2. 트렌드 관점에서 「분리배출 코치」를 평가한다. 유지할지, 재구성(같은 문제, 다른 프레이밍)할지, 교체할지 정한다.
3. 트렌드를 앞세우면서 SDG는 자연스럽게 붙는 후보를 3개 낸다. 각 후보마다 다음을 적는다.
   - 트렌드 근거
   - 피코의 필요성
   - LLM의 필요성
   - 12시간 MVP
   - 90초 시연 핵심
   - SDG(1개만)
   - 가장 큰 위험
4. 1순위와 이유를 적는다.

## 규칙
- 파일 쓰기는 `astra/round12_trend.md`만 허용한다. Command Code API는 호출하지 않는다. 미확인은 [추정]으로 표시한다.
- 끝으로 후보 3개와 1순위만 짧게 출력한다.

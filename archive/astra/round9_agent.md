# 9라운드: 더 어려운 과제 판정 (민원 현장 조사 에이전트)

모델: `openai-codex/gpt-6-astra`, `thinking=max`. 도구와 조사는 쓰지 않았다(2026-10-31 KST). 아래는 원문이다.

**1) 선택 — 수정 채택.** ‘사람 승인형 민원 조사 보조’로 좁힌다. LLM은 주장·조건 분해, 확인 질문, 측정 재계획을 맡고, 수치 비교·관측 상태 판정은 코드가 맡는다.
`tool_calls` 성공은 호출 가능성만 보여준다. **규칙으로 대체 불가능하다는 주장 대신, 고정 jev+템플릿보다 미리 짜지 않은 복합 조건·정정에 잘 대응하는지** 보여줘야 한다.
**2) 장면 A:** “차가 멈출 때만 시끄럽고 통로도 막힌다” → 신고자가 지목한 전후의 소리·거리를 비교하고, 결과가 엇갈리면 두 주장을 분리해 질문·측정 계획을 바꾼다.
**장면 B:** 낮 측정 뒤 “그 소리 말고, 비 오는 밤에 벽이 떨리는 것”으로 정정 → 기존 소음값을 해당 민원의 증거에서 제외하고, 시간·장비 한계를 밝혀 추가 확인으로 전환한다.
장면의 조건과 정정은 실행 중 바꿔라. 같은 입력에서 정정 반영·필요한 질문·불필요 호출을 템플릿과 비교하고, 차이가 없다면 LLM 채택 근거도 없다.
**3) 최소 도구:** `scan_distance`(서보+초음파), `measure_sound`(상대값), `ask_complainant`. 배경 비교·로그 저장은 코드로 처리하고, 현장 기록·답변 초안은 사람이 승인한다.
**12h에서 제외:** 진동·조도·수위·`sightline`, 과거기록 검색, 부서 자동 라우팅, 다중 노드·디지털 트윈. 도구 수보다 정정에 따른 조사 변경을 완성한다.
**4) 위험 A — 센서값의 과장:** 거리·상대 소리로 통행 방해·소음 원인·위반을 확정하지 않는다. ‘해당 조건에서 관측됨/미관측/측정 불가’를 구분하고, 미관측을 민원 부정으로 쓰지 않는다.
**위험 B — 느린 오호출 연쇄:** 측정 계획은 실행 전 사람 승인, 인자·서보 동작 범위·호출 상한은 코드로 제한한다. 불필요한 추가 측정을 막는 중단 조건을 둔다.
**5) 정직한 근거:** “제시된 2019~2025 수원 자료는 장기간의 민원 규모와 분야 다양성을 보여준다. 이를 배경으로 다양한 민원 설명을 다루는 조사 보조를 제안한다.”
5년 이상 반복 근거는 제시된 주정차·장애인 전용구역·어린이/통학 축에 한정한다. **소음·배수의 5년 지속이나 이 에이전트의 필요성이 검증됐다는 뜻은 아니다.**
2015~2025 부서 접수표는 과거 접수 분포다. 현행 담당부서를 확정하는 근거로 쓰지 않는다.

## Claude 반영
전부 수용했다. 실호출 시험에서 LLM이 초음파로 '막힘 요인'을 확인하려 한 사례가 나왔다(센서로 알 수 없는 것). 그래서 "관측 판정은 코드가 한다"는 원칙을 최우선으로 둔다. 설계는 `민원_조사_에이전트.md`에 정리했다.

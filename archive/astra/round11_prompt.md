# 11라운드: SDG 중심 과제 재선정 (독립 제안)

## 사용자 피드백
"주제 너무 별론데 지속가능발전 유의중? GPT랑 또 토의."
- 10라운드 안 '외국인 노동자 다국어 현장 안전 코치'(SDG 8.8)는 기각됐다.
- 이 메이커톤은 **UN SDG를 골라 해결하는 대회**다(포스터 조건). 사용자는 지속가능발전 색이 뚜렷한 주제를 원한다.

## 지금까지 사용자가 요구한 조건 (모두 지켜야 함)
1. 민원 자료만 쓰지 말고 **뉴스·정부·연구 자료로 정보를 넓힌다.** 수원과 연결되면 좋다. 수원 민원 키워드(2019~2025)는 `../data/evidence_summary.md`에 있다.
   - 예: 소각장 폐쇄·이전 2021~2024, 쓰레기 투기 2025, 주정차 7년
2. **라즈베리파이 피코를 쓰는 이유가 확실해야 한다.** 현장에서 센싱·구동하고, 네트워크 없이 로컬로 반응해야 한다.
3. **LLM을 쓰면 확실히 좋아야 한다.** 이전 토론의 교훈은 다음과 같다.
   - 센서 값이 구조화돼 있고 경우의 수가 작으면 규칙이 이긴다(등굣길 조사관 기각 이유).
   - LLM은 비정형 언어 입력(다양한 질문·설명), 공식 문서 근거 연결, 후속 질문, 센서 사실과 사람 말의 충돌 해결 같은 데서 제값을 한다.
   - 근거 인용은 코드가 대조한다.
4. **수준 있는 과제**여야 한다. 고교 메이커톤 심사위원이 보기에도 매력적이어야 한다.
5. 기존 조건은 그대로다.
   - 비초보 2~3인, 제작 12시간
   - Pico WH + 기본 센서(저가 추가 부품은 가격 표시)
   - Command Code API: chat `deepseek-v4.1-flash`는 도구 호출 실호출 정상(3.4~4.1초). jev는 ZDR 미지원. STT 모델 없음
   - 위반·자격 판정 금지, 사람 승인, 긴급 동작은 규칙
- 기각·철회된 주제(반복 금지): 주정차 접근성 경로 안내, 승차 인계, 수거 스테이션 넘침 알림, 배수 재실험, 공사 소음, 등굣길 위험 조사관, 민원 현장 조사 에이전트, 치매 대화 동반자, 외국인 노동자 안전 코치

## 할 일 (`astra/round11_sdg.md`, 한국어, 70줄 이내)
1. 웹 조사로 **SDG 핵심 영역**(기후·에너지·자원순환·물·식량·생태 등)에서 수원·경기와 연결되는 최근 이슈를 찾는다. 수치·날짜·출처 URL을 적는다.
2. 후보 3개를 낸다. 각 후보마다 다음을 적는다.
   - SDG 세부목표 번호
   - 뉴스 근거(URL)
   - 피코가 꼭 필요한 이유
   - LLM이 꼭 필요한 이유(규칙·룩업표로 안 되는 지점)
   - 12시간 MVP
   - 90초 시연 핵심 장면
   - 가장 큰 위험
3. 1순위를 고르고 이유를 적는다.

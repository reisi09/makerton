# 10라운드: 뉴스로 넓힌 과제 선택 판정

모델: `openai-codex/gpt-6-astra`, `thinking=max`. 도구와 조사는 쓰지 않았다(2026-10-31 KST). 판단 대상은 Claude가 뉴스로 확인한 사실과 후보 3개(1안 치매 야간 배회 대화 동반자, 2안 외국인 노동자 다국어 현장 안전 단말, 3안 고독사)였다. 아래는 원문이다.

- **최종 선택: 2안.** 센서 이벤트에 연결된 다국어 MSDS 근거 Q&A·훈련 단말. 뉴스로 문제 근거가 제시됐고, 음성 없이도 사용자 흐름이 성립한다.
- 1안은 치매 대상 진정 효과가 미검증이고, 10~16초 대화 루프와 미검증 로컬 STT가 핵심 체험의 위험이다. 실종 통계는 문제의 크기이지 대화의 효능 근거가 아니다.
- **피코 근거:** 노트북·API 응답과 독립적으로 센서 입력→LED/부저를 실행한다. MCU 역할은 분명하지만, Pico만 가능하다거나 기본센서가 산업용 안전장치를 대체한다고 과장하면 안 된다.
- **LLM 근거:** 작업자가 자기 언어로 던지는 비정형 질문·후속 질문을 MSDS 근거에 연결해 설명한다. 고정 번역문보다 유연한 역할은 명확하나, 정확도·학습 효과의 우위까지 확정할 근거는 없다.
- **12h MVP:** 기본센서→로컬 규칙 경보, 이벤트 맥락+지정 MSDS→Command Code 텍스트 Q&A, 원문 근거 병기. **STT 제외**, 서보는 억지로 넣지 않는다.
- 수준을 가르는 부분은 센서와 챗봇의 병렬 전시가 아니라 **현재 이벤트·작업 맥락에 연결된 근거 설명과 후속 질의**다. 작업 승인·위반판정은 하지 않는다.
- **시연 장면 A:** API 통신을 끊고 센서 입력을 변화시킨다. 로컬 LED/부저는 동작하고, 문서 대화의 이용 불가 상태는 구분해 표시한다.
- **시연 장면 B:** 해당 이벤트를 두고 외국어로 질문한 뒤 이해하지 못한 부분을 다시 묻는다. MSDS 근거 구절을 표시하며 설명을 바꾸는 과정을 보여준다.
- **위험·대응 — 오역·환각:** 원문 근거를 함께 표시하고 근거 밖 답변은 보류한다. 긴급 동작·지시는 규칙과 고정 문안으로 분리하고 LLM이 바꾸지 못하게 한다.
- **위험·대응 — 안전 과신:** 교육·설명 보조임을 명시한다. 실제 유해가스 시험은 하지 않고, 기본센서로 안전 여부를 판정하거나 기존 경보기·대피 체계를 대체하지 않는다.

## 2. GPT 1라운드에 대한 비판
1. **5년 근거 조건을 채우지 못한다.** 사용자가 요구한 것은 '5년 이상 민원 데이터를 근거로 한 아이디어'다. GPT의 5년치 자료(기본통계)는 증명 발급 위주라 어느 아이디어와도 연결되지 않는다. 2~5번 아이디어의 직접 근거는 한 달(2025-12), 한 구·한 해(2023 팔달구), 시설 수(빗물받이 70,579개), 정비 실적(포트홀)이다. 반면 Claude가 확보한 권익위 민원 빅데이터(E1·E2)는 2019~2026년 수원시 연도별 민원 건수와 연도별 키워드를 함께 준다. 이 자료가 있으면 주정차 계열(불법 주정차·인도·장애인 전용구역·충전구역·버스정류소)과 쓰레기 투기, 통학 환경은 다년 근거로 묶을 수 있다.
2. **USB 직렬만 쓰면 'Pico WH'의 무선을 버린다.** 직렬 연결도 함정이 있다. Thonny가 포트를 점유하고, pyserial을 설치해야 하고, 피코에서 비차단 stdin을 처리해야 한다. 그래서 Wi-Fi HTTP를 기본으로 하고 USB 직렬 브리지를 대체 경로로 두는 '둘 다' 방식을 제안한다. GPT가 짚은 핫스팟 단말 간 차단과 노트북 방화벽(Windows는 공용 네트워크에서 기본 차단)은 첫날 5분 안에 연결 점검 절차로 걸러낸다.
3. **생성형 서비스 층이 없다.** 사용자는 'Command Code API로 AI 서비스를 개발'하고 싶어 한다. jev 판단만 쓰면 결과가 LED에서 끝난다. 관리자나 시민에게 넘어가는 산출물(점검 요청서, 신고문 초안, 일일 요약)은 chat 모델로 만들고 사람이 확인하게 해야 민원과 행정이 이어진다. GPT 2번의 'AI가 문구를 생성하지 않는다'는 원칙은 피코 현장 표시에만 적용하는 것이 맞다.
4. **5번 요철 카트**는 기구 제작 위험이 크다(GPT도 인정). USB를 매단 채 미는 카트는 시연 재현성도 낮다. 탈락을 제안한다.
5. **4번 공사장 소음**은 근거가 2023년 팔달구 한 해뿐이다. 강당 소음 간섭도 크다. 다만 4개 구 환경위생과 접수 규모(2019~2023년 연 4,898~13,236건, 간접 근거)를 함께 쓰면 하위 후보로는 남길 수 있다.
6. **3번 빗물받이**는 민원 근거가 약하다. 그래도 SDG 11.5·13.1(기후 적응) 다양성과 수원시가 2026년 빗물받이 상태 데이터를 공개했다는 행정 관심을 근거로 하위 후보로 둘 수 있다.

## 3. GPT 지적을 예상한 Claude 자기 수정
1. **Claude 1번(전용구역)**: 초음파로는 '불법'을 판정할 수 없다. 실제 장애인 주차표지는 종이 스티커라 RFID 모사가 현실 도입과 거리가 있다. 수정안은 이렇다. 장치는 '위반 판정기'가 아니라 '점유 확인 요청기'다. 등록 차량 태그(아파트·공영주차장에서 쓰는 RFID 태그)나 운전자 확인 버튼이 없으면 안내하고, 오래 이어지면 관리자 확인을 요청하고 신고문 초안을 만든다. 사진은 사람이 첨부한다. 같은 장치에 구역 프로필(장애인 전용, 충전구역, 소방차 전용, 버스정류소)을 바꿔 끼운다. 그래서 Claude 5번(버스정류소)은 1번에 합친다.
2. **Claude 2번(소각장)**: '소각장 폐쇄 / 영통 소각장 / 영통 노후' 키워드는 시설 이전·폐쇄 요구다. 측정된 악취 사건이 아니다. MQ-135로는 소각 배출물을 특정할 수도 없다. 근거와 해법의 연결이 약하므로 최종 5개에서 빼고 '대안'으로 내린다.
3. **Claude 3번(스쿨존)**: 두 지점 속도 추정은 초보자 12시간에 버겁다. GPT 1번처럼 '진입부 점유 지속시간'으로 단순화하고, 보행자 대기(PIR)가 있을 때만 경고를 올리는 맥락을 더한다.

## 4. Claude가 제안하는 병합 5개(3라운드 합의 대상)
1. 교통약자·긴급 전용구역 점유 확인 요청기 (Claude 1+5, GPT 원칙 반영)
2. 통학로·횡단보도 진입부 점유 알림 (GPT 1 + Claude 3)
3. 공동 배출장소 넘침·방치 알림 (GPT 2 + Claude 4)
4. 빗물받이 배수 지연 경보 (GPT 3)
5. 공사장 지속 소음 작업 알림 (GPT 4)
- 대안: 영통 소각장 주변 공기질 기록·자동 환기(Claude 2), 요철 점검 카트(GPT 5)

## 5. 쟁점
- 통신: Wi-Fi 기본 + USB 대체(Claude) vs USB 기본(GPT)
- 생성형 AI(chat) 사용 범위: 관리자용 문서 생성 포함(Claude) vs 판단만(GPT)
- 근거 강도 평가: 권익위 다년 키워드를 직접 근거 5점으로 볼지(Claude) vs 동일 문제의 비교 가능한 직접 통계만 5점(GPT 기준)

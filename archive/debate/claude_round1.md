## 공통 구조(5개 아이디어에 모두 적용)
- 피코 WH + 센서 → (휴대폰 2.4GHz 핫스팟, HTTP JSON) → 노트북 중계 서버(Python 표준 라이브러리, `CMD_API_KEY` 보관) → Command Code API → 중계 서버가 동작 코드를 피코로 돌려줌 → LED·부저·서보·OLED
- 판단: `POST /systemone`(typesafe/jev). 센서 상태를 짧은 한국어 문장으로 보내고 typed question(noul/choice/score)의 확률을 받는다. 중계 서버는 그 확률에 임계값을 적용해 동작 코드로 바꾼다. 응답이 작아서 피코가 다루기 쉽다.
- 생성: `POST /chat/completions`(deepseek/deepseek-v4.1-flash). 민원 신고문 초안, 일일 리포트, 다국어 안내문을 만든다. 결과는 중계 서버 웹 대시보드에 한글로 보여 준다(SSD1306은 한글 폰트가 없으므로 OLED에는 숫자·영문·아이콘만 띄운다).
- 즉시 반응이 필요한 경고는 피코의 로컬 규칙이 먼저 낸다(반사). AI는 단계 상향, 오탐 억제, 기록·보고를 맡는다. 네트워크가 끊기면 로컬 규칙만으로 계속 동작한다.
- API 키는 피코에 저장하지 않는다. 기기를 분실하거나 전시 중 코드가 노출돼도 키가 새지 않는다. 피코에서 TLS를 쓰지 않으니 메모리와 시간도 아낀다.
- 비용[추정]: jev 1회 입력 약 300토큰 × 1,000회 = 30만 토큰 ≈ $0.013. deepseek 리포트 1회(입력 1k + 출력 0.5k) ≈ $0.00045. 시연 하루 전체가 $0.05 아래다.

## 1. 교통약자 전용구역 지킴이 (장애인 전용·친환경차 충전·소방차 전용구역)
- 문제·근거: 수원 민원 키워드 1위인 '불법 주정차' df가 2019년 16,139에서 2024년 190,307로 11.8배가 됐고, 2026년 1~10월에만 170,348이다(E2). '장애인 전용구역'은 2022~2026년 매년 12,791~18,651, '충전구역 불법주차'는 2023~2026년 매년 8,837~10,886이다(E2). 2026년 6월 국민신문고 유형 2위는 '장애인전용주차' 1,535건이다(E5). 2025년 단속 429,356건 중 32.6%가 주민의 안전신문고 신고다(E4). 시민이 직접 찍어 신고하는 부담이 크다는 뜻이다.
- SDG: 11.2(장애인 등 취약계층 교통 접근성), 10.2(사회적 포용)
- 하드웨어: HC-SR04(점유), RC522 RFID(장애인 주차표지·충전차량 카드 모사), RGB LED, 부저, SSD1306, SG90(안내 깃발)
- AI(jev): state = "구역=장애인전용, 점유 72초, 권한카드 없음, 경고 1회 무시, 시각 19:40". 질문은 세 개다. ① noul '자격 없는 주차 가능성' ② choice '조치 {없음, 안내, 강한경고, 관리자알림}' ③ score '보행·긴급차량 방해 위험 {낮음, 보통, 높음}'. ①이 0.7 이상이고 60초가 지나면 강한경고, 180초가 지나면 관리자알림을 낸다. 관리자알림이면 deepseek가 안전신문고 신고문 초안(위치·시각·구역·지속시간)을 대시보드에 띄운다. 자동 제출은 하지 않고 사람이 확인한다.
- MVP(12h): 주차면 1칸 디오라마, 센서 2종, 경고 3단계, 대시보드. 빼는 것: 번호판 인식, 실제 신고 연동.
- 시연: 장난감 차에 카드가 없으면 10초 뒤 노랑, 60초 뒤 빨강+부저, 대시보드에 확률과 신고문 초안이 뜬다. 카드가 있으면 초록 '이용 가능'.
- 리스크: 초음파 오탐(사람 통과)은 중앙값 필터와 5초 지속 조건으로 막는다. RFID 인식 거리는 약 3cm라 카드를 차 바닥에 붙인다.
- 부품: 키트 기본품이고 RC522가 없으면 약 3천원 추가.

## 2. 영통 소각장 주변 악취 감지 자동 환기창
- 문제·근거: '소각장 폐쇄' df 39,416(2022) → 20,771(2023) → 4,882(2024), '영통 소각장' 38,501(2023), '영통 노후' 23,747(2022) → 14,619(2024)(E2). 이전 논란은 2026년 10월까지 이어진다(E6). 행사장인 매원고가 영통구 매탄동에 있어 지역 연관성이 크다.
- SDG: 11.6(도시 대기질·폐기물), 3.9(오염 관련 질병 감소)
- 하드웨어: MQ-135(가스·VOC 상대값), DHT22, SG90(창·환기구 개폐), 릴레이+소형 팬, RGB LED. 선택으로 GP2Y1010 먼지센서(약 1만원).
- AI(jev): state = "MQ135 기준선 대비 +38%, 10분 상승 추세, 습도 72%, 바람 정보 없음, 21시". 질문: ① score '불쾌 악취 유입 가능성 {낮음, 보통, 높음}' ② choice '환기 {창열기, 창닫기+내부순환, 유지}' ③ noul '민원 기록이 필요한 이상 구간인가'. deepseek는 시간대별 기록을 주민이 민원에 붙일 '악취 발생 기록부'로 요약한다.
- MVP: 창문 모형 1개, 센서 2종, 자동 개폐, 기록 대시보드. 빼는 것: ppm 환산, 다지점 지도.
- 시연: 알코올 솜이나 식초를 가까이 대면 수치가 오르고, 창이 닫히고 팬이 돌고, 기록부에 한 줄이 생긴다.
- 리스크: MQ 센서는 보정이 안 돼 있으므로 '상대 변화'만 말하고 ppm을 표시하지 않는다. 예열이 수 분 걸린다. 특정 시설을 비난하는 틀이 아니라 '데이터로 소통하는' 틀로 발표한다.

## 3. 스쿨존·인도 보행안전 경보등
- 문제·근거: '어린이 보호구역' 13,975(2020), '통학환경 조성' 20,306(2021), '교육 환경' 29,134(2020) → 9,024(2022), '인도 불법(주차)' 20,615(2023) → 34,982(2024) → 31,182(2025)(E2)
- SDG: 3.6(교통사고 사상자 감소), 11.2(어린이 등 취약 이용자 안전)
- 하드웨어: 적외선 장애물 센서 또는 HC-SR04 두 개(두 지점 통과 시간으로 접근 속도 추정), PIR(횡단 대기자), HC-SR04(시야를 가리는 불법주차 차량), LED 바닥신호, 운전자용 LED 경고판, 부저
- AI(jev): ① score '보행자 충돌 위험 {낮음, 주의, 위험}' ② noul '불법주정차가 시야를 가리는가' ③ choice '경고 대상 {운전자, 보행자, 둘다, 없음}'. 실시간 경고는 피코가 로컬 규칙으로 바로 낸다. jev는 위험 등급과 오탐 억제에 쓴다. deepseek는 하루 위험 이벤트를 '통학로 개선 요청서' 초안으로 만든다.
- 시연: 경사로를 굴러오는 장난감 차, 인형 보행자, 가림 차량을 놓고 경고 단계가 바뀌는 모습을 보여 준다.
- 리스크: 속도 추정이 부정확할 수 있다. 센서 간격을 고정하고 통과 시간 차로 계산한다. 클라우드 지연이 있으므로 안전 경고를 AI 응답에 의존하지 않는다.

## 4. 무단투기 없는 클린존 배출함
- 문제·근거: '쓰레기 투기' 2,520(2025, E2). 수원시 청소·자원순환 부서 민원은 2015~2025년 연 2,880~4,199건으로 꾸준하다(E3). CCTV 403대로 단속하지만 식별이 안 된다는 보도가 있다(E6).
- SDG: 11.6(생활폐기물 관리), 12.5(폐기물 감축)
- 하드웨어: PIR, HC-SR04(적재량, 바닥에 놓인 물체), CdS(야간), LED 조명, 부저, SG90(뚜껑). 선택으로 HX711+로드셀(약 5천원).
- AI(jev): ① choice '이벤트 {정상배출, 무단투기의심, 단순통행, 수거필요}' ② score '적재 포화 {낮음, 보통, 높음}'. deepseek는 수거 요청서, 주간 투기 패턴 리포트, 외국인 주민용 다국어 배출 안내문을 만든다. 수원시는 다국어 쓰레기 안내서를 공공데이터로 내고 있다.
- 시연: 밤 모드에서 봉투를 바닥에 두고 떠나면 조명과 음성 경고가 나오고 대시보드에 '무단투기 의심'이 뜬다. 정상 배출이면 뚜껑이 열리고 감사 메시지가 나온다.
- 리스크: 카메라가 없어 개인을 식별하지 못한다. 이 점은 오히려 개인정보 측면의 장점이고, 대신 억제와 수거 최적화에 초점을 둔다.

## 5. 버스정류소 진입방해 경고 + 승차 도움벨
- 문제·근거: '버스정류소 불법' 6,019(2024) → 4,518(2025) → 3,470(2026, E2), '시내버스 운행' 8,710(2023, E2), 대중교통과 민원 2015~2025년 연 4,060~6,259건(E3)
- SDG: 11.2
- 하드웨어: HC-SR04(정차면 점유), 버튼(교통약자 승차 도움), LED 경고판, 부저, OLED
- AI(jev): ① noul '버스 진입을 방해하는 불법 정차인가' ② choice '조치 {대기, 운전자경고, 관리자알림}'. 버스 도착은 시연에서 버튼으로 모사한다(경기도 버스도착 API는 인증키가 필요해 선택 사항).
- 리스크: 1번과 감지 구조가 겹친다. 차별점은 '버스 도착'이라는 시간 맥락이다.

## 흔히 빠지는 함정
1. 안전신문고 유형 문구가 반복 집계된 키워드 값(2024년 23만대)을 민원 수로 인용하는 것
2. data.go.kr 15093355의 2024년 행(2023년 복제)과 2023년 집계 방식 변화를 무시하고 총량을 비교하는 것
3. MQ 센서 값을 ppm처럼 표시하는 것
4. 실시간 안전 경고를 클라우드 AI 응답에 걸어 두는 것(지연·끊김)
5. 행사장 Wi-Fi(캡티브 포털, 5GHz)에 피코를 붙이려다 시간을 잃는 것. 휴대폰 2.4GHz 핫스팟을 첫날 확인한다.
